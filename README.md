# English Practice Quiz

Ứng dụng luyện tập tiếng Anh dành cho học sinh, xây dựng bằng Next.js và Supabase.

## Chạy dự án

```bash
npm install
npm run dev
```

## Kiểm tra

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Test 5

```bash
npm run upload:test5
npm run import:test5
```

Các biến môi trường cần thiết được liệt kê trong `.env.example`.
